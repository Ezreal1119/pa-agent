# Library 一键同步失败重试

管理员同步任务 `40152ad2-eb9e-4634-8106-dc6fcb2b2124` 的 23 项错误中，4 项为图片模型返回不合协议的数据，19 项为中文图片描述/摘要翻译改变数字顺序、技术标识或命令。此前图片失败缓存会在下次同步中复用，无法靠「恢复同步」重新评估。

总同步现在对失败图片使用现有的严格重试入口；成功图片仍走成功缓存。翻译把数字、技术标识与既有的命令、路径、引用文本一起遮蔽为有序占位符，校验占位符顺序和恢复后的原文一致性，失败最多重新请求模型 3 次。首次真实恢复时 4 张原失败图片全部成功，但仍有 10 个摘要因模型反复打乱占位符而失败。因此补充片段翻译兜底：模型只翻译占位符之间的自然语言，程序按原顺序还原数字和技术内容，重组后仍通过原有逐项校验。只缓存验证通过的译文。模型最终仍不合格时保留错误状态和原有文件，不放松数字与命令安全校验。重新同步依旧按 Hash 复用未变化的成功结果。

本地验证：`npm run typecheck`、`npm run build`、`npm test`（184 项通过，2 项既有的非 Linux 环境跳过）。新增回归验证失败图片在下次一键同步中重试并保留成功缓存，以及数字/型号译文在模型首答错误后重新请求、验证和缓存。

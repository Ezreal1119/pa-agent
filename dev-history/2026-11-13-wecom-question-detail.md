# 企微问题 UUID 与回答查询

新消息通知附上已接收问答任务的 UUID 和 `/patrick_detail <uuid>`。通知接收账号可私聊同一机器人，读取该轮 Agent 的当前输出或完整回答，并查看排队、完成、失败、停止和中断状态。查询不进入模型、角色设置、附件处理或共享 Agent 队列；长回答沿用分段发送及投递恢复。

新增后端只读 Bridge 路由；运行时输出由正在执行的 HTTP 流维护，已结束/重启后的记录直接从 SDK 会话日志读取，不初始化模型。部署需要构建并重启主服务及 Bridge，无新增环境变量或依赖。

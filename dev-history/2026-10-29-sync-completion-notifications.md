# 2026-10-29 · Sync 完成通知与区间消费

用户要求每次 Sync 完成后向余额通知使用的个人账号发送结果，并汇总从上一次 Sync 完成到本次完成的模型费用，不按凌晨切分，不新增通知时间设置。

## 实现

- 新增 Sync 结束事件快照和持久通知 outbox、目标指纹、费用边界、通知租约与 ACK API。Bridge 复用现有连接和全局余额接收账号，只由第一个机器人私聊发送；不回退群或其他机器人，不调用 AI 生成通知。
- 手动 Sync、Re-Sync、失败/停止和新版本重启中断均生成结束记录；已存在历史报告不补发。自动同步轮次 ID 绑定子批次，保存不可变批次摘要，整轮只生成一个通知；空/忙/已处理跳过不通知、不推进边界。
- 状态包括文件数、入库/失败或中断/待处理/重复/未处理、最多八项文件简述、报告 ID，以及区间模型消费和本次 Sync 模型消费。投递延迟不重新计算金额或改变区间。
- 新增逐请求费用台账，SDK stream/result 钩子覆盖普通聊天（含 Web/WeCom/MCP）、Sync、记忆、研究、固件提取，独立 HTTP 视觉与 Library 分类也接入。使用 AsyncLocalStorage 绑定本次 Sync，跨模块不重复计价。台账无提示词、回答、密钥或附件正文。
- 不使用原 SDK 中手动配置的零价格。复用已有研究价格规则/适用的 RESEARCH_PRICING_JSON，记录价格版本，分开计算缓存与输入/输出。没有价格、没有 usage、未结算或启用前历史明确标为不完整。金额是 CNY 模型推理估算，不是完整服务商账单，不含外部搜索/抓取或其他项目费用。
- 结算与报告冻结使用文件锁和持久边界，晚结算/同毫秒记录归入后续区间；Bridge 成功片段检查点处理正常重启与 ACK 丢失去重。接收人变更不重放旧消息，检查点损坏只暂停通知，不停止普通聊天/同步。
- 自动同步终态只在结束事件保存后暴露，避免完成状态已可见、下一次触发却仍返回 skipped_busy 的竞态。

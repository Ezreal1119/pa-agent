# Pi 内置只读工具切换

用户确认先使用 Pi 内置 read、grep、find、ls。本轮在 ProductExpertCloud 实现，不修改 patrick-agent。

- Runtime 的显式工具名单替换为四个原生只读工具，对新建及恢复会话一致。没有自定义 shell 过滤，也没有继续向模型提供任意命令执行能力。
- 系统提示、两个已跟踪 Skill 模板和 `.data` 中的实际 Skill 改用对应检索参数。旧 Skill 备份在 `.data/maintenance-backups/2026-10-18-readonly-tools-001449/`。Memory 和知识正文未改。
- Web 调试仍保留旧工具调用日志，新增 grep/find/ls 的中文活动说明；计时和逐轮调用记录沿用现有实现。
- 23 项本机测试通过；新增真实 SDK + 本地模拟模型 HTTP 测试验证拒绝强行构造的四种非只读调用，且文件未变，并在 Git 忽略的知识目录验证四种只读检索成功。无真实模型问答或 VPS 验收。

本轮不是目录或 OS 沙箱：原生工具仍能读取进程可读的其他路径。运行持久化与过期清理保持正常。容器只读挂载及限制可读目录未实施，不能标为已完成。

# 固件资料库发布阶段的进度展示

原因：本机上传完成后，资料库发布复用 uploading / verifying_upload 阶段，云端复制还会将 bytes 清零。机器人只按 stage 显示“上传中”和字节百分比，产生“上传 80% → 上传 0%”的误解。

## 改动

- LocalJob 类型声明已有可选字段 library_state，客户端继续原样保留任务响应，无协议要求变更。
- 进度格式化结合运行状态、实际阶段及发布子状态识别对象检查、云端复制、对象校验和网页收录检查，显示“上传完成，正在发布到资料库……”，隐藏该阶段的字节百分比和速度。
- 正常传输沿用原百分比；未知字段、排队、等待重试、恢复和真实传输阶段不被遗留发布标记覆盖。取消时优先显示取消。
- 同一格式化方法继续供状态查询、定时通知和恢复提示使用，不新增通知或网络调用。
- 本机 Python 服务、上传/复制命令、重试、状态推进、结果校验和链接返回条件均未改动。

# 2026-10-14：桌面生成前图片确认与裁剪

用户希望把图片评分提前到 Excel 之前，并在最终生成前人工裁剪任意图片。裁剪只作用于当前任务，原 Library 不变；人工处理后不重新评分。修改范围限 pi-patrick，未部署云端、未运行真实模型或正式 Library 全量任务。

## 行为和实现

- 新桌面端的创建请求携带 `X-CKD-Image-Review: 1`。未带标识的旧客户端及管理员原入口沿用旧生成流程，避免旧版在未知确认状态等待。
- 最终脚本先依据冻结的来源 Hash 解析公共/项目有效资料、执行原工序资料评分，并返回当前任务的有效资料清单；此时不生成 Excel。服务使用原有图片评分与缓存机制评分，仅选实际进入 SOP 的图片，持久化图片确认状态。
- 桌面端可在原图上拖动角、边或选框，灰色范围不保留；支持选中全图、恢复原图和取消。图片预览通过鉴权客户端 API 提供；服务端用 sharp 按原图像素裁剪为任务私有 PNG，不改 Library、全库图片缓存或原图评分报告。
- 用户点击“生成 SOP”后，服务确认任务归属、版本号、脚本资产、有效资料与裁剪 Hash，再将裁剪图覆盖到独立的工序暂存副本中调用原 Excel 生成器。生成阶段不做视觉或文字模型调用。完成页保留原工序资料评分与 Excel；图片评分只在生成前展示，避免把原图分数说成裁剪后分数。
- 关闭应用/退出登录不取消任务。等待确认和裁剪选择保存在任务状态，可在后端重启后重新登录继续。完成或取消清理当前任务裁剪缓存；失败保留供显式恢复。旧任务/旧产物不回写。
- 新接口为 `GET/POST /api/client/runs/:id/images/:imageId` 与 `POST /api/client/runs/:id/generate`。新桌面主进程负责认证/图片请求，preload 只暴露限定业务方法；用户界面不获得任意文件系统/URL 权限。新桌面版本 0.1.3。

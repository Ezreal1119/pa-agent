# CKD 双向翻译质量校验与一次重试

## 原因和行为

原先翻译已保护数字、顺序、常见技术标识、引号中的 UI 标签和行数，但译文中残留原语言仍可能通过校验。SQ610 电池加热工序的“滴滴”在英文中保留即属此类；原文的 `ON/OF` 是源资料拼写，不能由翻译器自行改写。

`translateText` 在已有结构校验后增加保守的语言与数字单位检查：中译英找未受保护的汉字；英译中检查整句未转为中文及目标文本以英文为主时的原文短语复制；两方向对比秒、分、温度等带数字单位。斜杠按钮名按原文字面保护，拼写错误留给资料维护者。声音词“滴滴”等不作为 UI 标签锁定，可译成 beep。质量疑点只额外重试一次，第二次仍不合格则明确报错，不缓存结果、不写入 Library；原结构错误的既有重试及分段回退机制继续使用。

缓存读取会重新校验，坏缓存不再复用。一键同步的 Hash 快速路径对完整归属登记、未被人工改动的旧译文做只读质量检查，仅对异常目标重新生成；独立资料与人工更改的文件沿用原保护规则。JSON/JSONL 只检查可翻译的自然语言字段，短技术名称与常见英文 UI 词不因保留而被拒绝。检查本身不调用模型；旧译文正常时继续 Hash 复用。

## 验证

新增中译英拟声词、英译中英文残留、按钮/数值单位保护、失败不缓存、旧受管理译文按需修复和 JSONL 字段测试。测试模型调整为确实输出目标语言的伪本地化文本。对本机 Library 的 544 份现有受管理文本执行只读校验，0 份误判。`npm test`：200 通过、2 跳过、0 失败；`npm run typecheck`、`npm run build`、`git diff --check` 均通过。

# 管理员一键同步 Library

日期：2026-10-09。实施分支：`create-ckd-sop`，基于 main `170fa45`。

## 行为与边界

增加两个独立入口：**同步更新 Library** 和 **参考图片校准**。前者顺序执行语法检查、中英文同步、图片评分、图片描述与 summary/overview 更新；后者打开原有校准设置，由管理员单独执行。总同步不校准参考图，不改评分参数，也不在生成 SOP 时自动启动。没有修改通用 Agent Core、注册工具或新增依赖，没有修改、构建或测试 patrick-agent。

新增 `POST /api/library/sync`，请求为 `{}` 或 `{"dryRun":true}`，返回 202 和维护任务。只处理服务配置的完整 Library，不接受外部路径或局部筛选。现有单项 translate/summaries/validate、图片测试/校准/policy 接口保留；总接口调用业务模块，不向自身发 HTTP 请求。复用 `/api/library/jobs`、`/api/library/jobs/:id` 及对应 resume/cancel。

Web 增加四阶段进度、预览、恢复、取消和历史；报告显示语法文件/行列、冲突、错误、删除清单与图片评分。原校准按钮和参数编辑仍独立。API 沿用本地 Host/Origin 边界，可本机 curl 调用，没有引入新的管理员账号系统。

## 同步与恢复规则

- Library 外逐文件 Hash 基线识别变化。单边变化以变化的一侧为来源；中文仍存在且双边都变时，中文覆盖英文并报告。
- 首次无法核对来源的既有独立双语资料保留，建立基线，不凭 mtime 猜测谁修改过。可以验证的自动翻译记录会接管；新缺失语言会补齐。
- 删除跟随有归属且 Hash 未被人工修改的自动对应文件；独立或人工修改内容保留并报告。保存缺失状态，避免下一次把主动删除当成缺失重新补齐。中文删除、英文同时人工编辑时也保护英文，不报告成中文覆盖。
- 空文件、空目录及项目对公共资料的空值覆盖保留；目录创建/删除也进入事务。整个工序删除会清理有归属的对应目录及未被改写的旧摘要，非空人工目录保留。
- 每任务使用原跨进程 Library 锁，与 SOP 执行阶段互斥。语法错误停止后续全部阶段；翻译错误停止评分和摘要。单图片失败继续其余图片和摘要，任务报告部分失败。
- 复用备份、暂存、Hash 复核、逐文件原子替换和提交日志，扩展删除与回滚。反向同步迁移翻译归属，保存提交后基线检查点。重启后显式恢复，重新扫描并复用已提交结果，不自动调用模型。
- 每个同步任务固定评分策略、校准和规则版本。原图按 Hash 去重，跨语言共享分析缓存；已缓存图片也按本任务参数算分。当前图片索引剔除已删除图片，历史任务保留原结果。
- 摘要仍使用旧维护器识别的原始业务字段、照片命名、语言隔离、公共继承和项目覆盖规则；Hash 未变化时复用。已跟踪的失效摘要只在 Hash 未被外部修改时删除。不会为未知文件类型添加新的摘要语义。

新增模块 `library-sync.ts` 与 `library-sync-translation.ts`；任务类型、维护事务、source/translation、HTTP 和 UI 接入现有实现。基线及当前图片索引保存于 `.data/ckd/library-cache/<Library-realpath-Hash>/`；任务及事务/备份继续位于 Library 外、Git 忽略的目录。没有新增文件监听器，管理员修改后手动触发。

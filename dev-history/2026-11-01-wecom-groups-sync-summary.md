# 企微独立群卡片与同步摘要群通知

## 页面与数据

- 联系人与群组在同一页面显示独立卡片，分别显示 User ID / Chat ID、所属机器人、备注、提问和 Token；搜索覆盖两类卡片。
- 联系人现有 ID、备注和个人统计保留，存储版本继续为 1，新增可选 `groups` 与 `groupCursors`。从已有联系人群关联、Bridge 群会话映射和消息身份导入群卡片，不改 Bridge 映射。
- 群身份按 Bot ID + Chat ID 隔离，与同名个人或其他机器人分开；管理员群备注沿用登录及请求令牌校验。
- 同一群的多名发言人合并计入群统计，同时各自保留个人统计。页面总览仅汇总个人统计，不重复计数。群统计游标独立、幂等；加载旧会话时可从原始运行记录补记群统计，不重记个人统计，不从个人总量猜测历史群用量。
- 默认群会话标题可显示群备注；自定义会话标题不覆盖，不修改日志或模型上下文。姓名与群名均以文本渲染。

## 同步通知

- 原个人同步通知完整保留，消费边界与余额报送不变。
- 可选 `WECOM_SYNC_GROUP_CHAT_ID` 指定一个群；`WECOM_SYNC_GROUP_BOT_ID` 可选，缺省使用第一个已配置机器人。机器人须在目标群内。
- 群内容直接从同一份同步完成事件生成摘要，仅包含结束时间、状态、文件数量和文件更新结果，不读取费用台账，不转发个人完整版。
- 群使用独立的持久队列、目标指纹和分片检查点；Claim/ACK 显式带群类型，个人与群独立恢复和重试。首次启用或更换群不回放旧通知。
- 只复用已有机器人连接，不新增长连接或计划任务。群通知为空时关闭，不改变个人通知目标。

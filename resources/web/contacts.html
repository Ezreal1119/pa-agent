WECOM CONTACTS

WeCom contacts & groups

Contacts and groups have their own cards. Add a display name to a person or group, and use User IDs or Chat IDs to identify notification recipients. Custom conversation titles keep their names.

Questions count agent runs that actually started, including failed or stopped runs. File-only uploads and new-conversation commands are excluded. Group usage is shown on both the group and the sender cards; the overview counts each question and token only once. Usage includes shared context and model requests triggered by tools.
Existing group IDs are imported. Historical group usage is restored only where original run records are available; missing usage is not inferred. Deleting or expiring a conversation does not reset totals. Only usage reported to the server is counted; missing usage is not estimated. Input includes cached tokens; output includes reasoning tokens already counted by the provider. These totals are not a bill.
